# pygame

## Esquadrão 1945

Jogo de aviões em pygame, no estilo do 1945 Air Force (disciplina Design de Software).

## Como rodar
```
pip install pygame
python jogo.py
```
Na primeira vez o jogo cria sozinho as imagens e sons em `assets/`.

## Controles
- Setas ou WASD: mover
- Espaço: atirar
- ESC: sair

## Regras
- Derrube caças (100 pts) e bombardeiros (500 pts)
- Moedas valem 50 pts
- Power-up P: tiro duplo, depois triplo + 2 aviões de ala
- Vida extra a cada 1000 pontos, nova fase a cada 2000
